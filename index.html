Translate Genie

Translate Genie is an AI-powered translation support platform designed to help Translation Studies students explore languages, understand translations, and practice different forms of expression across Tamil, English, Sinhala, and beyond.

AI-generated translations should still be reviewed carefully, especially for academic, legal, technical, or highly contextual and cultural content.

Supported languages

Tamil, English, and Sinhala are the primary languages, with quick-select buttons for all three. Dozens more — including Hindi, Malayalam, Telugu, Kannada, Bengali, Urdu, Arabic, Chinese, Japanese, Korean, French, German, Spanish, and many others — are searchable from the "Other" and language-change menus. You can also type in any language name Gemini can translate, even if it isn't in the suggested list.

Listen / pronunciation

The speaker button first tries Google's Gemini text-to-speech for a natural voice. If that's ever unavailable (offline, rate-limited, etc.), it automatically falls back to your browser's own built-in voice. That fallback works in every modern browser, but which languages it can actually speak depends on the voices installed on your device — Chrome and Edge on Windows or Android generally have the widest language coverage; Safari and Firefox support varies more by operating system, especially for Tamil and Sinhala.

Your Gemini API key

This site runs entirely in your browser — there is no server. Your key is saved only in this browser's local storage and is sent straight from your browser to Google's API when you translate. Never enter your key on a version of this site you don't control or trust, and never share this key with others.

How do I get a Gemini API key?
  1. Go to Google AI Studio → Get API key and sign in with your Google account.
  2. Click Create API key. If asked, choose or create a Google Cloud project — the free option works fine for this app.
  3. Copy the key Google generates. It's a long string starting with AIza....
  4. Paste it into the field above and click Save key.
  5. That's it — Translate Genie will use it for every request from this browser. You can come back here anytime to update or remove it.

Google's Gemini free tier is generous for personal study use, but has a request-per-minute limit — if translations suddenly fail, wait a minute and try again.
